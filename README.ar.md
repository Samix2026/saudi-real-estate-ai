---

## نبذة عن المشروع

`saudi-real-estate-ai` قاعدة معرفة مفتوحة المصدر ومنظَّمة، تضمّ أنظمة العقارات السعودية والمنصات الرسمية والجهات التنظيمية وأنواع العقود والمصطلحات المتخصصة — صُمِّمت لخدمة وكلاء الذكاء الاصطناعي والمطورين والباحثين الذين يبنون تطبيقات عقارية للسوق السعودي.

يُنظِّم المستودع البيانات التنظيمية الموثَّقة من المصادر السعودية الرسمية (هيئة العقار، إيجار، وافي، سكني) في مجموعات بيانات JSON قابلة للقراءة آليًا، وتعريفات JSON Schema، وبرامج نصية ثنائية اللغة، واستشهادات بالمصادر. وكل مجموعة بيانات ثنائية اللغة (عربي / إنجليزي) ومُحقَّقة من خلال مخطط، مما يجعلها جاهزة للتكامل مع أنابيب RAG وخوادم MCP وروبوتات الدردشة ووكلاء الذكاء الاصطناعي التي تحتاج إلى معرفة عقارية سعودية موثوقة.

## نطاق المشروع

| المجال | التفاصيل |
|---|---|
| الأنظمة واللوائح | نظام العقار، لوائح الإيجار، قواعد البيع على الخارطة |
| المنصات | إيجار (عقود الإيجار)، وافي (البيع على الخارطة)، سكني (برامج الإسكان) |
| الجهات | هيئة العقار، وزارة البلديات والإسكان، الجهات البلدية |
| العقود | الإيجاري، البيع، البيع على الخارطة، الإيجار التجاري |
| المصطلحات | قاموس ثنائي اللغة للمصطلحات العقارية السعودية |
| مخرجات الذكاء الاصطناعي | برامج نصية للنظام، أسئلة وأجوبة تجريبية، مخططات JSON Schema |
| أنواع العقارات | 15 نوعاً عقارياً بتعريفات قانونية وصكوك واشتراطات التملك |
| الكود السعودي للبناء | أكواد SBC وحقوق المشتري والتزامات المطور |
| صناديق الاستثمار العقاري | الإطار التنظيمي لصناديق REITs المدرجة في تداول |
| برامج الإسكان | 7 برامج وطنية: سكني، صندوق التنمية العقارية، NHC، روشن وغيرها |
| الترميز العقاري | أنظمة العنوان الوطني والتسجيل العيني وتعريف قطع الأراضي |

## حالات الاستخدام

- بناء روبوتات دردشة عقارية سعودية مستندة إلى بيانات تنظيمية موثَّقة
- تزويد وكلاء الذكاء الاصطناعي بمعرفة منظَّمة وقابلة للاستشهاد حول نظام العقار السعودي
- التحقق من عقود الإيجار وفق الأنظمة السعودية واشتراطات منصة إيجار
- مراجعة امتثال الوسطاء والمطورين لمتطلبات الترخيص من هيئة العقار
- تحليل مخاطر شراء الوحدات على الخارطة باستخدام بيانات منصة وافي
- دعم تأهيل المستثمرين الأجانب عبر أدلة ثنائية اللغة لدخول السوق
- إثراء أنابيب الاسترجاع المعزَّز (RAG) بمعرفة متخصصة في القطاع العقاري السعودي
- تدريب النماذج اللغوية أو ضبطها الدقيق على المصطلحات العقارية العربية
- توجيه المستثمرين الأجانب عبر مسارات التملك المُصنَّفة حسب الجنسية (خليجي، مقيم، غير مقيم) باستخدام `data/foreign-investor.ar.json`
- التحقق من أهلية الوسيط العقاري ومتطلبات ترخيصه عبر `data/broker-requirements.ar.json`
- تشغيل بحث في قاموس المصطلحات العقارية الثنائي اللغة المتضمن أكثر من 50 مصطلحاً رسمياً
- بناء مستشارين افتراضيين لحقوق المستأجرين يشرحون التزامات نظام الإيجار وإجراءات المنازعات في منصة إيجار
- استخدامه كطبقة معرفية موثوقة لوكلاء MCP العقاريين المتصلين بواجهات برمجة تطبيقات السوق السعودي
