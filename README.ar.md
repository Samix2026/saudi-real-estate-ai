## نبذة عن المشروع

`saudi-real-estate-ai` قاعدة معرفة مفتوحة المصدر ومنظَّمة، تضمّ أنظمة العقارات السعودية والمنصات الرسمية والجهات التنظيمية وأنواع العقود والمصطلحات المتخصصة — صُمِّمت لخدمة وكلاء الذكاء الاصطناعي والمطورين والباحثين الذين يبنون تطبيقات عقارية للسوق السعودي.

يُنظِّم المستودع البيانات التنظيمية الموثَّقة من المصادر السعودية الرسمية (هيئة العقار، إيجار، وافي، سكني) في مجموعات بيانات JSON قابلة للقراءة آليًا، وتعريفات JSON Schema، وبرامج نصية ثنائية اللغة، وخادم MCP جاهز للتشغيل. وكل مجموعة بيانات ثنائية اللغة (عربي / إنجليزي) ومُحقَّقة من خلال مخطط، مما يجعلها جاهزة للتكامل مع أنابيب RAG وخوادم MCP وروبوتات الدردشة ووكلاء الذكاء الاصطناعي التي تحتاج إلى معرفة عقارية سعودية موثوقة.

## التكامل مع MCP

اربط قاعدة المعرفة مباشرةً بـ Claude Desktop كأدوات قابلة للاستدعاء.

**1. تثبيت مكتبة MCP:**

```bash
pip install mcp>=1.0.0
```

**2. إضافة الخادم إلى إعدادات Claude Desktop:**

macOS: `~/Library/Application Support/Claude/claude_desktop_config.json`

```json
{
  "mcpServers": {
    "saudi-real-estate-ai": {
      "command": "python3",
      "args": ["/المسار/المطلق/إلى/saudi-real-estate-ai/mcp/server.py"],
      "env": {}
    }
  }
}
```

**3. أعِد تشغيل Claude Desktop.** ستظهر الأدوات الـ 8 في قائمة الأدوات:

| الأداة | الوصف |
|---|---|
| `search_terms` | البحث في قاموس المصطلحات الثنائي (83 مصطلح) |
| `get_property_type` | تعريفات العقارات وأنواع الصكوك وقيود التملك |
| `check_broker_requirements` | ترخيص الوسيط العقاري من هيئة العقار |
| `get_housing_programs` | سكني وصندوق التنمية العقارية وNHC وروشن وغيرها |
| `get_reits_framework` | قواعد هيئة CMA لصناديق REITs ومتطلبات تداول |
| `get_building_code` | اشتراطات الكود السعودي للبناء |
| `get_foreign_investor_rules` | قواعد التملك الأجنبي حسب فئة الجنسية |
| `get_property_coding` | أنظمة العنوان الوطني والتسجيل العيني وقطع الأراضي |

راجع [`mcp/README.md`](mcp/README.md) لتعليمات الإعداد الكاملة.

## حالات الاستخدام

- بناء روبوتات دردشة عقارية سعودية مستندة إلى بيانات تنظيمية موثَّقة
- تزويد وكلاء الذكاء الاصطناعي بمعرفة منظَّمة وقابلة للاستشهاد حول نظام العقار السعودي
- التحقق من عقود الإيجار وفق الأنظمة السعودية واشتراطات منصة إيجار
- مراجعة امتثال الوسطاء والمطورين لمتطلبات الترخيص من هيئة العقار
- تحليل مخاطر شراء الوحدات على الخارطة باستخدام بيانات منصة وافي
- دعم تأهيل المستثمرين الأجانب عبر أدلة ثنائية اللغة لدخول السوق
- ربط Claude Desktop بجميع مجموعات البيانات مباشرةً عبر خادم MCP
- إثراء أنابيب الاسترجاع المعزَّز (RAG) بمعرفة متخصصة في القطاع العقاري السعودي
- توجيه المستثمرين الأجانب عبر مسارات التملك المُصنَّفة حسب الجنسية
- بناء مستشارين افتراضيين لحقوق المستأجرين يشرحون التزامات نظام الإيجار
